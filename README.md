# Trabalho-BD-Faculdade

Essa é uma **Modelagem de Banco de Dados** feita para um trabalho da **Faculdade (FATEC)**, onde é realizado a:
- ### Criação de Cenário
- ### Descrição Textual
- ### Modelo Conceitual (DER)
- ### Modelo Lógico
- ### Modelo Físico (SQL)
- ### CRUD
  - **C** - CREATE
  - **R** - READ
  - **U** - UPDATE
  - **D** - DELETE
